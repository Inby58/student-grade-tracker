📖 About This Project

An overview of how grades are computed, tracked, and visualized.

Made by Izzat

The Student Grade Tracker is designed for teachers and educators to quickly evaluate class performance, record test scores, and analyze pass/fail distributions in real time with Chart.js visual graphics.

Grading Scale

Grade Score Range Status

B 70.0% – 79.9% ✓ Pass
C 60.0% – 69.9% ✓ Pass
D 50.0% – 59.9% ✓ Pass
F 0.0% – 49.9% ✕ Fail
